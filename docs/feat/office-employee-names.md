# Office employee names

Customize the selected running employee's name in the same compact row style as
the existing Pet selector. Clearing the name restores the session tab label.
The name appears above the Pet with palettes and effects for all nine built-in
scenes. Pause, reduced-motion and visibility settings also govern nameplate motion.

Names belong to full instance/tab/binding identities, so reused tabs and seats do
not inherit another employee's name. They survive acknowledged saves, reopening
and renderer takeover. Session and recent-result searches accept the same names.

Both name and Pet maps share a bounded metadata budget. Reclaim their retired
entries together, preserve live bindings, and match native Gson escaping in the
frontend byte checks. Native schema validation and IPC/frame limits remain in
force. Group membership and desk exchanges are a separate dependent contribution.

Validation includes name parsing and migration, aggregate-budget regressions,
native round trips and IPC limits, failed-save recovery, independent bindings,
and browser checks for theme changes, pause and reduced motion.
