# Office visual assets and controls

This topic adds the nine bundled vector room themes and their geometry, viewport/zoom controls, desk previews, result history, and motion/effect controllers. It is separated from native window/storage integration and does not change the production entry point.

Animation is owned by a single clock, pauses when hidden or reduced motion is requested, and releases listeners/frames on disposal. Viewport fitting preserves logical desk hit targets. Decorative scene layers and bundled SVGs add no navigation or executable command authority.

Validation: focused Office Vitest suites, test TypeScript compilation and production build. Asset tests check all bundled themes, geometry and vector scene restrictions. The final live-page topic supplies browser acceptance across desktop viewports.
